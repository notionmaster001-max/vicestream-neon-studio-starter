## 💻 How to Add to OBS Studio in 30 Seconds

1. In your OBS Gameplay Scene, click **`+`** under Sources → select **Browser**.
2. Check **`[x] Local file`** and browse to `overlays/webcam-border.html`.
3. Set **Width: `640`**, **Height: `400`**.
4. In your Sources list, drag the `Webcam Border` directly above your webcam video capture source.
